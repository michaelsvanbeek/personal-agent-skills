# Tag Registry

All skills in this repository must be tagged with one or more persona tags from
this registry. Tags help users browse skills relevant to their role.

## Recognized Tags

| Tag | Description |
|-----|-------------|
| `developer` | Software engineers, SREs, DevOps engineers |
| `manager` | Engineering managers, project managers, team leads |
| `analyst` | Data analysts, business analysts, BI specialists |
| `designer` | UX designers, UI designers, product designers |
| `writer` | Technical writers, content creators, copywriters |
| `researcher` | Academic researchers, UX researchers, market researchers |
| `operations` | Operations managers, program managers, chiefs of staff |
| `marketing` | Marketing managers, growth leads, demand gen specialists |
| `sales` | Account executives, sales engineers, SDRs |
| `support` | Customer support agents, success managers |
| `executive` | C-suite, VPs, directors — strategic and cross-functional work |
| `communication` | Cross-role tag for skills about writing, presenting, or meeting facilitation |
| `general` | Universally applicable skills not tied to a specific persona |

## Rules

- Tags are lowercase, single-word or hyphenated
- Every skill must have 1-5 tags
- Use role-based tags (who benefits), not technology tags (what tool it uses)
- Prefer existing tags — propose a new tag via PR only if no existing tag fits
- New tags must include a description and at least 3 skills that would use them

## Proposing a New Tag

Open a pull request that:
1. Adds the tag to the table above
2. Updates at least 3 existing skills that should carry the new tag
3. Explains in the PR description why existing tags are insufficient
