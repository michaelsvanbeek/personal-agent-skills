# Researcher Skills

Skills for academic researchers, UX researchers, and market researchers.

## Recommended Skills

| Skill | Description |
|-------|-------------|
| [literature-review](../../skills/literature-review/SKILL.md) | Synthesizing papers and identifying themes |
| [citation-standards](../../skills/citation-standards/SKILL.md) | APA, Chicago, and other citation formats |
| [academic-writing](../../skills/academic-writing/SKILL.md) | Paper structure, abstracts, and academic tone |

## Recommended MCP Servers

| Server | Purpose |
|--------|---------|
| Filesystem | Access local papers and notes |
| Zotero | Manage references and citations |
| Google Scholar | Search academic literature |
| Google Docs | Draft and collaborate on papers |

## Getting Started

1. Install citation-standards and literature-review skills
2. Connect Filesystem MCP for local paper access
3. Add academic-writing when drafting papers

## Example Prompts

```
Summarize the key findings from these five papers.
```

```
Draft an abstract for a paper on this research topic.
```

```
Check this bibliography for APA formatting consistency.
```
