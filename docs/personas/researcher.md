# Researcher Skills

Skills for academic researchers, UX researchers, and market researchers.

## Recommended Skills

| Skill | Description |
|-------|-------------|
| [alternatives-analysis](../../skills/alternatives-analysis/SKILL.md) | Compare research options and document trade-offs with evidence |
| [data-analysis](../../skills/data-analysis/SKILL.md) | Run reproducible exploratory analysis and statistical summaries |
| [data-visualization](../../skills/data-visualization/SKILL.md) | Present findings clearly with static or interactive charts |
| [markdown-docs](../../skills/markdown-docs/SKILL.md) | Structure research documentation and decision records |
| [prompt-writing](../../skills/prompt-writing/SKILL.md) | Build and evaluate high-quality prompts for research workflows |

## Recommended MCP Servers

| Server | Purpose |
|--------|---------|
| Filesystem | Access local papers and notes |
| Zotero | Manage references and citations |
| Google Scholar | Search academic literature |
| Google Docs | Draft and collaborate on papers |

## Getting Started

1. Install citation-standards and literature-review skills
2. Connect Filesystem MCP for local paper access
3. Add academic-writing when drafting papers

## Example Prompts

```
Summarize the key findings from these five papers.
```

```
Draft an abstract for a paper on this research topic.
```

```
Check this bibliography for APA formatting consistency.
```
