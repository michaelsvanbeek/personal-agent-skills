# Writer Skills

Skills for technical writers, content creators, and copywriters.

## Recommended Skills

| Skill | Description |
|-------|-------------|
| [markdown-docs](../../skills/markdown-docs/SKILL.md) | Documentation structure, formatting, linking |
| [editorial-standards](../../skills/editorial-standards/SKILL.md) | Grammar, style, and consistency rules |
| [tone-guide](../../skills/tone-guide/SKILL.md) | Voice, tone, and audience-appropriate writing |

## Recommended MCP Servers

| Server | Purpose |
|--------|---------|
| Google Docs | Read and draft documents |
| Notion | Manage content in a knowledge base |
| Filesystem | Access local markdown and text files |
| Slack | Gather context from team discussions |

## Getting Started

1. Install markdown-docs and editorial-standards skills
2. Connect Google Docs or Notion MCP servers
3. Add tone-guide if you maintain a brand voice

## Example Prompts

```
Review this README for structure and readability.
```

```
Rewrite this paragraph in a more approachable tone for a non-technical audience.
```

```
Check this document for consistency with our editorial standards.
```
