# Analyst Skills

Skills for data analysts, business analysts, and BI specialists.

## Recommended Skills

| Skill | Description |
|-------|-------------|
| [sql-style](../../skills/sql-style/SKILL.md) | SQL formatting, naming, and query patterns |
| [chart-design](../../skills/chart-design/SKILL.md) | Choosing chart types, axes, accessibility |
| [data-storytelling](../../skills/data-storytelling/SKILL.md) | Presenting findings to non-technical audiences |

## Recommended MCP Servers

| Server | Purpose |
|--------|---------|
| BigQuery / PostgreSQL | Query production or warehouse databases |
| Google Sheets | Read and write analysis results |
| Slack | Share findings with stakeholders |
| Filesystem | Access local CSV/Parquet files |

## Getting Started

1. Install sql-style and chart-design skills
2. Connect your data warehouse MCP server
3. Add data-storytelling when preparing reports

## Example Prompts

```
Write a query to find monthly active users by acquisition cohort.
```

```
Recommend a chart type for this retention data and describe the axes.
```

```
Summarize these query results in plain language for a product manager.
```
