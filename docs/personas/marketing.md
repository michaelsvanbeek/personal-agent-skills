# Marketing Skills

Skills for marketing managers, growth leads, and content strategists.

## Recommended Skills

| Skill | Description |
|-------|-------------|
| [brand-voice](../../skills/brand-voice/SKILL.md) | Tone, voice, and messaging consistency |
| [campaign-planning](../../skills/campaign-planning/SKILL.md) | Campaign structure, timelines, deliverables |
| [content-calendar](../../skills/content-calendar/SKILL.md) | Editorial planning and content scheduling |

## Recommended MCP Servers

| Server | Purpose |
|--------|---------|
| Google Drive | Read briefs, draft copy, manage spreadsheets |
| Slack | Coordinate with agencies and creative teams |
| Outlook / Gmail | Draft outreach and review inbound |
| Notion | Manage content calendar and brand guidelines |

## Getting Started

1. Install brand-voice and campaign-planning skills
2. Connect Google Drive and Slack MCP servers
3. Add content-calendar for recurring content workflows

## Example Prompts

```
Draft a product launch email in our brand voice.
```

```
Create a campaign brief for this quarter's product launch.
```

```
Build a content calendar outline for the next 4 weeks.
```
