# Designer Skills

Skills for UX designers, UI designers, and product designers.

## Recommended Skills

| Skill | Description |
|-------|-------------|
| [design-review](../../skills/design-review/SKILL.md) | Reviewing designs for usability and consistency |
| [accessibility](../../skills/accessibility/SKILL.md) | WCAG compliance, ARIA patterns, keyboard navigation |
| [component-specs](../../skills/component-specs/SKILL.md) | Specifying components for engineering handoff |

## Recommended MCP Servers

| Server | Purpose |
|--------|---------|
| Figma | Access design files and components |
| Slack | Coordinate with engineering and product |
| Notion | Manage design documentation |
| Filesystem | Access local design tokens and specs |

## Getting Started

1. Install design-review and accessibility skills
2. Connect Figma MCP server if available
3. Add component-specs when handing off to engineering

## Example Prompts

```
Review this component spec for accessibility issues.
```

```
Write a component specification for this design that engineering can implement.
```

```
Check this color palette for WCAG AA contrast compliance.
```
