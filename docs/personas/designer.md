# Designer Skills

Skills for UX designers, UI designers, and product designers.

## Recommended Skills

| Skill | Description |
|-------|-------------|
| [accessibility-testing](../../skills/accessibility-testing/SKILL.md) | Automate WCAG checks and build accessibility regression tests |
| [charts](../../skills/charts/SKILL.md) | Build accessible chart visuals with clear labels and contrast |
| [markdown-docs](../../skills/markdown-docs/SKILL.md) | Document UI decisions and component behavior clearly |

## Recommended MCP Servers

| Server | Purpose |
|--------|---------|
| Figma | Access design files and components |
| Slack | Coordinate with engineering and product |
| Notion | Manage design documentation |
| Filesystem | Access local design tokens and specs |

## Getting Started

1. Install accessibility-testing and charts
2. Connect Figma MCP server if available
3. Add markdown-docs when handing off component decisions to engineering

## Example Prompts

```
Review this component spec for accessibility issues.
```

```
Write a component specification for this design that engineering can implement.
```

```
Check this color palette for WCAG AA contrast compliance.
```
